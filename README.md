# BrandVRtise-Unity

The surviving implementation is a small Unity UI/pulse prototype with newer and older project folders and a Windows-build workflow. Declared ads, analytics, and purchasing packages do not establish an implemented advertising service or a matching browser data-package importer.

## Current state

Unity UI/pulse prototype with project variants. Documentation describes inspected source and configuration; no runtime, device, player-build, deployment, or rights certification is implied. The default branch is `development`.

## Start here

Read [development instructions](docs/development.md) for the supported opening/inspection route and [known issues](docs/known-issues.md) before attempting execution. Validate HelloWorld and PulseObject in the intended variant; separately repair workflow path, build entry, and license logging before CI use.

## Important implementation and value

Preserves a bounded UI animation example, two editor-era variants, and historical automation intent.
